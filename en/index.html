How to start

Windows

  1. Right-click the downloaded archive → “Extract All”. Do not start the game from inside the archive.
  2. Extract it to a folder such as C:\Games. Do not choose Program Files: the game cannot update itself there.
  3. Open the “Contra Petukhov” folder and run Contra Petukhov.exe.
  4. If you see “Windows protected your PC”, click “More info” → “Run anyway”.

The Windows version is a test one: if something does not work, tell the person who sent you the link.

Mac

  1. Open the downloaded disk image (double-click): a window with an arrow appears.
  2. Drag Contra Petukhov onto the Applications shortcut, otherwise the game will not update. Then eject the image (Finder → Eject) and open the game from Applications.
  3. macOS will warn that it cannot verify the developer. Close that window with “Done”.
  4. Open System Settings → Privacy & Security, click “Open Anyway” near the bottom and confirm. On macOS 14 and older, just right-click the game → “Open”.

Later updates are downloaded by the game itself when you log in.
