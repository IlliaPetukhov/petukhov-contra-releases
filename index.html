Як запустити

Windows

  1. Клацніть по скачаному архіву правою кнопкою миші → «Видобути все» (так Windows називає розпакування). Не запускайте гру прямо з архіву.
  2. Розпакуйте, наприклад, у теку C:\Games. Не обирайте Program Files: там гра не зможе оновлюватися.
  3. Відкрийте теку «Contra Petukhov» і запустіть Contra Petukhov.exe.
  4. Якщо Windows покаже «Windows захистив ваш комп'ютер»: «Докладніше» → «Усе одно запустити».

Версія для Windows тестова: якщо щось не працює, напишіть тому, хто дав вам посилання.

Mac

  1. Відкрийте скачаний образ (подвійний клік): з'явиться вікно зі стрілкою.
  2. Перетягніть Contra Petukhov на ярлик «Програми», інакше гра не оновлюватиметься. Потім витягніть образ (Finder → Витягти) і відкрийте гру з «Програм».
  3. macOS попередить, що не може перевірити розробника. Закрийте це вікно кнопкою «Готово».
  4. Відкрийте «Системні параметри» → «Приватність і безпека», унизу натисніть «Усе одно відкрити» й підтвердьте. На macOS 14 і старіших досить клацнути по грі правою кнопкою → «Відкрити».

Наступні оновлення гра завантажує сама під час входу.
