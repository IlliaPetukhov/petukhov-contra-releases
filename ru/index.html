Как запустить

Windows

  1. Нажмите на скачанный архив правой кнопкой мыши → «Извлечь все». Не запускайте игру прямо из архива.
  2. Распакуйте, например, в папку C:\Games. Не выбирайте Program Files: там игра не сможет обновляться.
  3. Откройте папку «Contra Petukhov» и запустите Contra Petukhov.exe.
  4. Если появится «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае».

Версия для Windows тестовая: если что-то не работает, напишите тому, кто дал вам ссылку.

Mac

  1. Откройте скачанный образ (двойной щелчок): появится окно со стрелкой.
  2. Перетащите Contra Petukhov на ярлык «Программы», иначе игра не будет обновляться. Затем извлеките образ (Finder → Извлечь) и откройте игру из «Программ».
  3. macOS предупредит, что не может проверить разработчика. Закройте это окно кнопкой «Готово».
  4. Откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и подтвердите. На macOS 14 и старее достаточно нажать на игру правой кнопкой → «Открыть».

Следующие обновления игра скачивает сама при входе.
